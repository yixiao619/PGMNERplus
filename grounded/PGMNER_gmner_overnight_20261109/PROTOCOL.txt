Objective: Improve same-protocol GMNER F1 beyond independently evaluated Qwen GMNER adapter (64.652348 on835 TEST), while retaining explicit attribution and original results. No guarantee. No manuscript changes.
Frozen inputs: PGMNER entity predictions, independent end-to-end GMNER adapter epoch3 predictions, raw and context-grounding caches. Union of predicted mention/type candidates only. Candidate outputs consist of None plus unique complete region sets from existing systems. Original multi-box outputs preserved. No gold candidates.
GPU pass: for every predicted entity, text-only A/B verification of exact span/type with reversed choices; for each region/None hypothesis, visual evidence verification with reversed choices. Region verification uses full image plus square-letterboxed candidate crops mapped from resized coordinates to original pixels. None verification asks explicitly whether entity is visually absent. Worker input contains no target gold. Restricted-token scores are not calibrated probabilities.
Training: regularized logistic C=.01/.1/1 and shallow histogram boosting, seed42. Five-fold DEV grouped by normalized post text; all candidate outputs for a post remain in one fold. Target is official joint tuple correctness. No raw text/image identity features. OOF predictions select 3 operating modes: filter teacher triples only; change regions/None for teacher entities; allow PGMNER-only candidate additions. Each mode uses thresholds .2/.3/.4/.5/.6/.7: 72 learned configurations, plus unchanged independent teacher which wins ties. Full DEV refit after lock, before TEST processing. Training is decision-layer calibration on reused DEV, not base-model fine-tuning.
Automatic schedule: prepare DEV predicted-only jobs -> three GPU shards -> grouped calibration training -> DEV lock -> prepare TEST jobs -> three GPU shards -> evaluate locked winner and teacher -> paired bootstrap and per-post results -> stop. No adaptive TEST optimization. Preserve all DEV trials and unsuccessful outcomes. TEST was previously examined; results exploratory. If teacher wins, report fallback rather than fusion success. No claim that teacher benefits prove PPIB/GOTA improvements.
Output: source hash, job manifests, raw scoring outputs, fold assignments, full DEV trials, locked config/model, metrics, post counts, prediction files, status/logs. Existing experiment directories remain untouched. Stop on error, caches support restart after clean interruption.

Sequential exploratory GMNER experiments. No manuscript changes or overwriting earlier predictions. All three rounds execute regardless of TEST outcome. DEV selects each rule before TEST preparation. Same 835-post previously examined TEST; no claim of fresh confirmation.
R1: Preserve exact mention/type agreements; verify symmetric-difference candidates independently using the post and image. A/B single-token conditional likelihood verifies mention AND type, not visual presence. Thresholds independently per candidate source [.5,.65,.8,1.01] selected by DEV joint F1. Accepted conflicts resolved by option-score descending; reject overlapping mention strings already retained. Grounding comes from teacher or context PG source as available. No arbitrary rewriting.
R2: Fixed PGMNER entity list with anchored teacher grounding. Pool unique boxes from original, context and independent complete-task predictions, add None. Whole-image and region-crop inputs; candidates in original resized-image coordinate frame, crops converted back to source pixels. Select by conditional option-token likelihood, confidence thresholds [0,.5,.7,.9,1.01] choose on DEV. Low confidence falls back to anchored baseline. DEV candidate oracle only diagnostic and not consumed by worker/selection. Not a gold-box selector.
R3: Repeat R1 with two TRAIN examples retrieved by context token overlap normalized by example length, excluding mention tokens from query. TRAIN rows with exact normalized text overlap with any DEV/TEST post excluded. Examples provide text and gold entity/type pairs only. This is a simple retrieval baseline, not full reproduction of a published retrieval model. No heldout labels in prompts.
All inference job files exclude target gold. Label access in preparation audits old cache alignment and computes optional DEV oracle only. Worker reads jobs only. Choice probabilities are restricted-answer softmax scores, not calibrated probabilities. Per-source thresholds selected on DEV. Seed42 existing checkpoints frozen; no model training. Cache files resumable after clean interruption.
Retain independent teacher, consensus, anchored controls in reports. Improvements over PGMNER do not establish improvement of PPIB/GOTA or superiority over independent teacher. Negative/zero outcomes retained. Each round stores metrics, frozen config, per-post predictions and counts.
